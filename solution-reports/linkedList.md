## What is a linked list?

A linked list is an array like data structure that stores "list" of data. Unlike an array which stores its data in a squential memory locations, linked lists are made up of indivdual nodes that have a pointer/reference to the next node in the linked list.

---

## Features of a linked list

- Has a head element at the start.
- Each node contains a value and "points" to the proceeding node in the list.
- There is no backwards pointers, it's not possible to move backwards through the list.
- The final element (tail) has the value of null, signifying that there is no other element in the list.
